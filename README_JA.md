## これは何か

Ami は東風集団の AI コラボレーション プラットフォームです。従業員はそれぞれ 1 つの
アシスタント（東風助手）を持ち、専用のワークスペース、ファイルシステム、ブラウザ、
長期記憶を利用できます。エキスパートとスキルはそのアシスタントに仕えるサブロールであり、
個別に管理する実体ではありません。

プラットフォームは社内イントラネット上に完全にセルフホストされます。外部 SaaS に
依存せず、データを外部へ送信しません。

## 主な機能

- **独立したワークスペース**：アシスタントごとに専用のファイルシステム、ネットワーク、ブラウザ
- **長期記憶**：セッションをまたいで好み、習慣、過去の判断を記憶
- **エキスパートとスキル**：エキスパート ロールを割り当て、利用可能なスキルを選択
- **スケジュール タスク**：定型業務を定期的に実行し、結果をアプリ内で通知
- **社内モデル接続**：推論はすべて社内のモデル基盤を経由

## デプロイ

社内サーバー上に Docker Compose でデプロイします。手順と環境変数の詳細は
[DEPLOYMENT.md](DEPLOYMENT.md) を参照してください。

```bash
cp conf/app.docker.toml config.toml
# 環境に合わせて config.toml を編集
export AMI_INTERNAL_RPC_SHARED_SECRET="$(openssl rand -hex 32)"
docker compose up -d
```

Compose は Server と Channel を別サービスとして起動します。内部 RPC シークレットは
厳重に管理し、再作成時も同じ値を使用してください。

## ディレクトリ構成

| パス | 内容 |
| --- | --- |
| `apps/web` | Web フロントエンド（Vue 3 + Vite） |
| `apps/desktop` | デスクトップ クライアント（Electron） |
| `internal/` | バックエンド サービス（Go） |
| `packages/ui` | デザイン システムとコンポーネント ライブラリ |
| `packages/icons` | アイコン セット |
| `skillhub/` | 社内スキル レジストリ |
